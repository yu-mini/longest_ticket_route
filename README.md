# 最長片道切符の旅

駅と路線の情報を標準入力から受け取り同じ駅を2回通らずに移動できる最長を経路を求め、通る駅のIDを順番に出力するプログラムです。

## 動作環境

- python 3.8 以上
- 標準ライブラリを使用しているため、追加のインストールは不要です
- Windows / Mac / Linuxで動作します

## 使い方

### ファイルから入力する場合

**Windows（PowerShell）**

```
Get-Content input.txt | python main.py
```

**Windows（コマンドプロンプト）/Mac/Linux**

```
python main.py < input.txt
```

※ Mac/Linuxでは`python`ではなく`python3`を使う場合があります

### 手で入力する場合

```
python main.py
```

実行後、1行ずつ入力し、最後に

Windowsの場合は`Ctrl + Z` を押してから`Enter`

Mac/Linuxの場合は`Ctrl + D`

### 入力の形式
 
```
始点のID, 終点のID, 距離
```
 
例（`input.txt`）
 
```
1, 2, 8.54
2, 3, 3.11
3, 1, 2.19
3, 4, 4
4, 1, 1.4
```
 
### 出力の例
 
最長経路で通る駅のIDを、通る順に改行コード（`\r\n`）区切りで出力します。
 
```
2                        
1
4
3
2
```

同じ長さの経路がある場合そのうち1つの経路を出力します（上の例だと1→2→3→4→1なども同じ長さです）。どの経路が出力されるかは丸め誤差に左右されます。
 
## 仕様の解釈
 
問題文で明確に決まっていない点は、次のように判断しました。
 
- 路線は双方向に移動できるものとして扱います（無向グラフ）
- 空行、数値の前後の空白、ファイル先頭のBOMは無視します
- 同じ路線を往復するだけの経路（例：1→2→1）は、始点に戻る経路として扱いません
## 考え方
 
- 入力から、各駅について「行ける駅とその距離」をまとめた一覧（隣接リスト）を作ります
- すべての駅を出発点として、深さ優先探索（DFS）で同じ駅を通らない経路をすべて調べます
- 駅に着くたびにそこまでの距離を最長記録と比べ、長ければ記録を更新します
- 次の駅が出発駅で、3駅以上通っている場合は、出発駅に戻る経路も候補として比べます
深さ優先探索を選んだのは、今たどっている1本の経路だけを覚えておけばよく、「通った駅」の記録を戻りながら消していくことで、同じ駅を2回通らない条件を管理しやすいためです。
